01 / 08

Why do we need loops?

Imagine printing numbers from 1 to 100. Writing 100 separate console.log() statements would be slow and unnecessary. Loops solve this problem.

01

Repetition

Run the same instructions multiple times without rewriting code.

02

Automation

Let JavaScript handle repetitive tasks automatically.

03

Efficiency

Write shorter, cleaner and easier-to-maintain programs.

without-loop.js OLD APPROACH 
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);
with-loop.js SMART APPROACH 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

// Output: 1 2 3 4 5
02 / 08

How does a loop work?

Most loops follow a repeating process. A starting value is created, a condition is checked, the code runs, and the value is updated.

ANATOMY OF A LOOP
STEP 01

Initialize

Create the starting variable.

STEP 02

Condition

Check if the loop should continue.

STEP 03

Execute

Run the statements inside the loop.

STEP 04

Update

Change the variable and check again.

loop-structure.js BREAKDOWN 
for (
    let i = 1;    // Initialize
    i <= 5;       // Condition
    i++           // Update
) {
    console.log(i); // Execute
}
03 / 08

The for loop

A for loop is useful when you know how many times you want to repeat a task.

Initialize
let i = 1
Creates a variable and sets its starting value.
The loop begins with i equal to 1.
Condition
i <= 5
The loop continues while this condition is true.
When i becomes 6, the loop stops.
Update
i++
Increases the value of i by one after each iteration.
The next iteration uses the updated value.
for-loop.js EXAMPLE 
for (let i = 1; i <= 5; i++) {
    console.log("Welcome to JavaScript");
}

// Prints the message five times.
04 / 08

The while loop

A while loop repeats a block of code as long as its condition remains true. It is useful when the number of repetitions is not known in advance.

while-loop.js EXAMPLE 
let count = 1;

while (count <= 5) {
    console.log(count);
    count++;
}

// Output: 1 2 3 4 5

Important: Remember to update the variable inside the loop. Otherwise, the condition may stay true forever and create an infinite loop.

05 / 08

The do...while loop

This loop executes its code block at least once, then checks the condition. Even if the condition is false initially, the code runs once.

do-while.js EXAMPLE 
let number = 1;

do {
    console.log(number);
    number++;
} while (number <= 5);

// Output: 1 2 3 4 5
A

do

Executes the code block first.

B

while

Checks the condition after execution.

C

Repeat

Runs again if the condition is true.

Compare the three loops

All three loops repeat code, but each has a different use case.

LOOP BEST USED WHEN RUNS AT LEAST ONCE?
for Repetition count is known No
while Condition controls repetition No
do...while Code must run before checking Yes

08 / 08

Control your loop

JavaScript gives you special statements to change the normal flow of a loop.

break

Stops the entire loop immediately, even if the condition is still true.

if (i === 3) break;

continue

Skips the current iteration and moves to the next iteration.

if (i === 3) continue;
break-example.js STOP THE LOOP 
for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        break;
    }

    console.log(i);
}

// Output: 1 2
continue-example.js SKIP ONE ITERATION 
for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}

// Output: 1 2 4 5

Nested loops

A nested loop is a loop placed inside another loop. The inner loop completes its repetitions for every single iteration of the outer loop.

nested-loop.js EXAMPLE 
for (let i = 1; i <= 2; i++) {

    for (let j = 1; j <= 3; j++) {
        console.log(i, j);
    }

}

// Output: (1,1) (1,2) (1,3)
//         (2,1) (2,2) (2,3)
