ELEMENT EXPLAINER
📄

DOCTYPE Declaration

The DOCTYPE declaration tells the browser that this document uses modern HTML5 standards. It should be the first line of an HTML document.

<!DOCTYPE html>
Remember: DOCTYPE is a declaration, not a normal HTML element.
01 / DOCUMENT COMPONENTS

Know the important building blocks.

These elements work together to create a properly structured HTML document.

COMPONENT 01

The HTML Element

The root element of the page. All other HTML elements, except the DOCTYPE declaration, are placed inside it.

<html lang="en"> ... </html>
COMPONENT 02

The Head Section

Contains document information such as the title, metadata, stylesheet links and other resources.

<head> ... </head>
COMPONENT 03

The Body Section

Contains the visible webpage content such as headings, paragraphs, images, buttons and links.

<body> ... </body>
COMPONENT 04

The Title Element

Defines the webpage title that usually appears in the browser tab and helps identify the page.

<title>My Website</title>
02 / IMPORTANT DECLARATION

Why do we write DOCTYPE?

A small declaration makes a big difference in how the browser interprets your document.

<!DOCTYPE html>

Use HTML5 standards mode.

This declaration tells the browser to render the page using modern standards rather than an old compatibility or quirks mode. Place it at the very beginning of the file.

03 / FROM CODE TO SCREEN

What does the browser display?

The head contains document information. The body contains the content that visitors see on the webpage.

yourwebsite.com

Hello World!

Look at the difference.

The browser tab gets its title from the title element inside the head. The heading, paragraph and link are displayed because they are inside the body.

This separation keeps document information and visible content organized.
