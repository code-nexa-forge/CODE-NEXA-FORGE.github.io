01 / UNDERSTANDING

What is the DOM?

The Document Object Model connects your HTML document with JavaScript.

Document Object Model

The DOM is a programming interface that represents an HTML document as a tree of objects. JavaScript uses this structure to access, modify, add, and remove elements on a webpage. When a browser loads HTML, it creates a DOM tree that JavaScript can interact with.

03 / SELECTORS

Selecting HTML Elements

JavaScript provides several methods to find elements inside the DOM.

getElementById()

Select by ID

Returns the element with the specified ID.

getElementsByClassName()

Select by Class

Returns a collection of elements with the same class.

getElementsByTagName()

Select by Tag

Finds elements using their HTML tag name.

querySelector()

First CSS Match

Returns the first element matching a CSS selector.

querySelectorAll()

All CSS Matches

Returns all matching elements in a NodeList.

document.body

Access the Body

Provides direct access to the document body element.

04 / MODIFICATION

Modifying DOM Elements

Once an element is selected, JavaScript can change its text, HTML, styles, and attributes.

01. Change Text

Use textContent to update the text inside an element.

document.querySelector("h1").textContent = "Hello!";

02. Change HTML

Use innerHTML to read or replace HTML markup. Only use trusted or safely handled content.

element.innerHTML = "<strong>Hello</strong>";

03. Change CSS

Update inline styles using the style property.

element.style.color = "blue";

04. Change Attributes

Use setAttribute() to add or update HTML attributes.

element.setAttribute("title", "Welcome");
05 / ELEMENT CREATION

Creating New Elements

JavaScript can create new HTML elements and insert them into the document.

Create an Element

createElement() creates a new HTML element in memory.

const newItem = document.createElement("p");
newItem.textContent = "New paragraph";

Add it to the Page

appendChild() inserts a node inside another element.

document.body.appendChild(newItem);
06 / INTERACTION

JavaScript Events

Events allow JavaScript to respond when users interact with a webpage.

EVENT 01

click

Triggered when an element is clicked.

EVENT 02

mouseover

Triggered when the pointer enters an element.

EVENT 03

keydown

Triggered when a keyboard key is pressed.

EVENT 04

submit

Triggered when a form is submitted.

EVENT 05

change

Triggered when a form control value changes.

EVENT 06

input

Triggered when the value of an input changes.

EVENT 07

load

Triggered when a resource or page finishes loading.

EVENT 08

dblclick

Triggered when an element is double-clicked.

Event Listeners

addEventListener() attaches an event handler to an element. It lets you run a function when a particular event occurs.

const button = document.querySelector("button");

button.addEventListener("click", function() {
  console.log("Button clicked!");
});

08 / EVENT FLOW

Event Bubbling

Event bubbling means an event starts at the target element and then travels upward through its parent elements.

Parent Element

Child Element

// Click the button to observe event bubbling.

The event travels from the clicked button to its child container and then to the parent container. You can stop this behavior using event.stopPropagation().

Stopping Event Propagation

stopPropagation() prevents the event from continuing to travel through the DOM tree.

button.addEventListener("click", function(event) {
  event.stopPropagation();
});
