01

What Is a Variable?

Understanding how JavaScript stores information.

A variable is a named container used to store data. You can think of it as a labeled box where JavaScript keeps information that your program can use later.

For example, a website might store a user's name, age, email address, or whether someone is logged in. Variables make this information available whenever your code needs it.

📦

Store Data

Variables keep information available inside your program.

🏷️

Give It a Name

Every variable has an identifier that helps you access its value.

⚡

Use It Anywhere

Read or update a variable when your program needs its data.

example.js 
let username = "Your Name";
let age = 20;

console.log(username);
console.log(age);

Variable Name

username is the name used to access the stored information.

Variable Value

"Your Name" is the actual information stored in the variable.

02

let, const and var

Three ways to declare variables in JavaScript.

JavaScript provides three keywords for declaring variables: let, const, and var. Each one behaves differently.

Keyword Can Reassign? Scope Modern Usage
let Yes Block Common
const No Block Recommended by default
var Yes Function Older code

Using let

Use let when a variable's value needs to change later.

let-example.js 
let score = 10;

score = 25;

console.log(score); // 25

Using const

Use const when you do not intend to reassign the variable.

const-example.js 
const country = "Pakistan";

console.log(country);

Using var

var is the older way of declaring variables. It has function scope rather than block scope, so modern JavaScript generally prefers let and const.

var-example.js 
var city = "Multan";

city = "Lahore";

console.log(city);
Remember: Prefer const when reassignment is not needed. Use let when the value must change. Avoid var in most modern JavaScript code.
03

Variable Naming Rules

Create clear and valid variable names.

Variable names are called identifiers. JavaScript has rules that determine which names are valid.

✓ Valid Names

userName
totalPrice
_counter
$amount
age2

✕ Invalid Names

2age
user-name
first name
let
total price

Variable names cannot start with a number, cannot contain spaces, and cannot use reserved JavaScript keywords. JavaScript identifiers are case-sensitive: age and Age are different variables.
naming-example.js 
let firstName = "Your Name";
let totalPrice = 500;
let isLoggedIn = true;
04

JavaScript Data Types

Different kinds of information JavaScript can work with.

A data type describes what kind of value a variable contains. JavaScript has several built-in data types.

String Text values
Number Numeric values
Boolean True or false
Undefined Not assigned
Null Intentional empty value
Object Structured data
BigInt Very large integers
Symbol Unique identifiers
data-types.js 
let username = "Your Name";  // String
let age = 20;                  // Number
let isStudent = true;          // Boolean
let address;                    // Undefined
let result = null;             // Null

let student = {
    name: "Your Name",
    age: 20
};                              // Object
Important: JavaScript is dynamically typed. You do not need to declare a variable's data type separately. Its type is determined by the value assigned to it.
05

The typeof Operator

Find out what type of value a variable contains.

The typeof operator returns a string describing the type of a value. It is useful when checking data in your code.

typeof-example.js 
console.log(typeof "Hello"); // string
console.log(typeof 25);       // number
console.log(typeof true);     // boolean

let value;
console.log(typeof value);    // undefined

console.log(typeof {});       // object
JavaScript quirk: typeof null returns "object". This is a historical behavior in JavaScript, not an indication that null is actually an object.
