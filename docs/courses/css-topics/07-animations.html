01 / THE BASICS

Animation vs Transition

CSS transitions create smooth changes between two states, while CSS animations can run through multiple stages using keyframes.

CONCEPT_01

CSS Transitions

A transition smoothly changes a CSS property when a state changes, such as when a user hovers over a button.

.button {
  transition: background .3s ease;
}

.button:hover {
  background: lime;
}
CONCEPT_02

CSS Animations

Animations use @keyframes to define different stages of movement, color, size, rotation and more.

@keyframes move {
  from { transform: translateX(0); }
  to { transform: translateX(100px); }
}

.box { animation: move 2s infinite; }

04 / IMPORTANT PROPERTIES

Animation property reference.

These properties give you control over how an animation behaves.

Property Purpose
animation-name Chooses the keyframes animation to run.
animation-duration Sets how long one animation cycle takes.
animation-delay Waits before the animation starts.
animation-iteration-count Controls how many times the animation repeats.
animation-timing-function Controls the speed pattern of the animation.
animation-direction Controls whether animation runs forward, backward or alternates.
