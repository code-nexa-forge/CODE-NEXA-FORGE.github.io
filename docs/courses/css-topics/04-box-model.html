01 / THE CONCEPT

What is the CSS Box Model?

The CSS Box Model describes how every HTML element is displayed as a rectangular box.

Think of a cardboard box 📦

Imagine a product packed inside a cardboard box. The product is the content, the space around it is padding, the cardboard edge is the border and the outside gap between boxes is margin. CSS works in a similar way.

PART 01

Content

The actual text, image or other material inside an element.

PART 02

Padding

Space between the content and its border.

PART 03

Border

The visible edge surrounding padding and content.

PART 04

Margin

Space outside the border that separates elements.

03 / CSS PROPERTIES

How to Use Each Property

Padding

Adds space inside an element, between its content and border.

.box { padding: 25px; }
Extra Inner Space

Margin

Adds space outside an element, separating it from other elements.

.box { margin: 25px; }
Outer Space

Border

Creates an outline around the element.

.box { border: 4px solid green; }
Visible Border

Width & Height

Set the dimensions of the content area by default.

.box { width: 200px; height: 80px; }
200 × 80
04 / SIZING SYSTEM

Understanding box-sizing

The box-sizing property controls how an element's total width and height are calculated.

content-box (Default)

With content-box, padding and border are added outside the specified width and height.

.box { width: 200px; padding: 20px; border: 5px solid green; box-sizing: content-box; } /* Total width = 250px */

border-box

With border-box, padding and border are included inside the specified width and height.

* { box-sizing: border-box; }

This is a popular global setting because it makes layouts easier to calculate and control.
