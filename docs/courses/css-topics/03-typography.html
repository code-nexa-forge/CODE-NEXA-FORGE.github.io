THE FOUNDATION

What is Typography?

Typography is the art of arranging text to make it clear, attractive and easy to read.

Why does typography matter?

Imagine visiting a website where every heading, paragraph and button uses the same tiny font. It would be difficult to read and understand. Typography creates visual hierarchy, improves readability and gives a website its personality.

02 / 06
THE TOOLKIT

Six Essential CSS Properties

These properties give you control over the appearance of text.

PROPERTY / 01 Aa

font-family

Chooses the typeface used for text.

p { font-family: Arial, sans-serif; }
PROPERTY / 02 ↕

font-size

Controls how large or small text appears.

h1 { font-size: 40px; }
PROPERTY / 03 B

font-weight

Controls the thickness of text.

h2 { font-weight: 700; }
PROPERTY / 04 ≡

text-align

Aligns text to the left, center or right.

p { text-align: center; }
PROPERTY / 05 ↕

line-height

Controls the vertical space between lines.

p { line-height: 1.8; }
PROPERTY / 06 ↔

letter-spacing

Controls the space between individual letters.

h1 { letter-spacing: 3px; }
