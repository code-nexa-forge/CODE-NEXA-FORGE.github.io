01 — THE CONCEPT

What exactly is CSS?

First, understand the role CSS plays in building a website.

CSS

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control how HTML elements look on a webpage. With CSS, you can change colors, fonts, spacing, layouts, backgrounds, animations and much more.

Think of HTML as the structure of a house and CSS as its paint, decoration, furniture and interior design.

01 / STRUCTURE

HTML builds the content

HTML tells the browser what elements exist on the page.

<h1>Hello World</h1>
02 / APPEARANCE

CSS styles the content

CSS tells the browser how those elements should appear.

h1 { color: orange; }
02 — THE SYNTAX

Understand CSS syntax

Every CSS rule follows a simple structure.

h1 {
  color: orange;
  font-size: 40px;
}
Selector Chooses which HTML element you want to style. Example: h1
Property Defines what you want to change. Example: color
Value Defines the setting for that property. Example: orange
Declaration A property and its value together, ending with a semicolon.
