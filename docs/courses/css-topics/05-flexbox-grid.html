01 / THE CONCEPT

Two powerful layout systems.

Flexbox and Grid are CSS layout systems. They help you position elements without using difficult floats or unnecessary positioning.

SYSTEM_01

Flexbox

Flexbox is a one-dimensional layout system. It arranges elements in a row or a column. Use it for navigation bars, buttons, cards and aligning items.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
SYSTEM_02

CSS Grid

Grid is a two-dimensional layout system. It controls rows and columns together. Use it for galleries, dashboards and complete page layouts.

.container {
  display: grid;
  grid-template-columns:
  repeat(3, 1fr);
}

04 / WHEN TO USE WHAT?

Flexbox vs Grid

Choose Flexbox

When you need to arrange items in one direction, such as a navbar, a row of buttons, or vertically aligned content.

Choose Grid

When you need rows and columns together, such as a photo gallery, product listing or dashboard layout.
