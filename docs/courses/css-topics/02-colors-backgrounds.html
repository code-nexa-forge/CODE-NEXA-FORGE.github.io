01 / UNDERSTANDING COLORS

How CSS Colors Work

CSS allows you to change the color of text, backgrounds, borders and almost every visible element.

What is a CSS Color?

A CSS color is a value that tells the browser which color should be displayed on an element. You can use color names, HEX values, RGB and HSL.

h1 { color: cyan; } p { color: #20e3d2; } button { background-color: rgb(56, 169, 255); }

Color Names

Use predefined names like red, blue, tomato and cyan.

HEX Colors

Use hexadecimal codes such as #a855f7.

RGB Colors

Mix red, green and blue values to create colors.

02 / BACKGROUND STYLING

CSS Background Properties

Background properties control what appears behind an element.

Background Color

The background-color property sets a solid color behind an element.

body { background-color: #071521; }

Background Image

You can use an image as the background of an element.

body { background-image: url("background.jpg"); background-size: cover; background-position: center; }

Background Repeat & Size

These properties control how an image fits and repeats inside its element.

.hero { background-image: url("hero.jpg"); background-repeat: no-repeat; background-size: cover; background-position: center; }
