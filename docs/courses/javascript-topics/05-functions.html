01 / THE FOUNDATION

What is a Function?

Understand the idea before writing your first function.

A reusable block of code

A function is a block of code designed to perform a particular task. You write it once and call it whenever you need it. Instead of repeating the same code again and again, you can put that code inside a function.

f(x)
02 / FUNCTION TYPES

Build your understanding

Explore the main ways to create and use functions in JavaScript.

CONCEPT 01

Function Declaration

A function declaration creates a named function using the function keyword. You can call it by its name.

function welcome() { console.log("Welcome!"); } welcome();
CONCEPT 02

Parameters

Parameters are variables written inside the function parentheses. They receive values when the function runs.

function greet(name) { console.log("Hello " + name); } greet("Student");
CONCEPT 03

Arguments

Arguments are the actual values you pass into a function when calling it.

function add(a, b) { console.log(a + b); } add(10, 20); // 10 and 20 are arguments
CONCEPT 04

The return Statement

Return sends a value back from a function. That value can be stored in a variable or used in another expression.

function multiply(a, b) { return a * b; } let result = multiply(4, 5); console.log(result);
CONCEPT 05

Arrow Functions

Arrow functions provide a shorter syntax for writing functions using the arrow symbol.

const greet = () => { console.log("Hello!"); }; greet();
CONCEPT 06

Function Expressions

A function expression stores a function inside a variable. It can then be called using that variable.

const sayHello = function() { console.log("Hello!"); }; sayHello();
Important: A parameter is the variable in the function definition. An argument is the actual value passed when calling the function.

06 / VARIABLE SCOPE

Where can variables be used?

Scope determines where a variable can be accessed in your code.

Local Scope

A variable declared inside a function is generally accessible only inside that function.

function test() { let message = "Hello"; }

Global Scope

A variable declared outside functions can usually be accessed throughout its accessible scope.

let website = "CNF"; function show() { console.log(website); }
Remember: Variables declared with let and const are block-scoped. A function also creates its own local scope.
