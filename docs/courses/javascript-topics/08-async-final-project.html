01 — THE CONCEPT

What is Asynchronous JavaScript?

Not every operation finishes instantly. Async JavaScript helps your application stay responsive while waiting for results.

01 /

Synchronous

Code runs one statement at a time. The next statement waits until the current operation finishes.

02 /

Asynchronous

Some operations can complete later while JavaScript continues executing other available work.

03 /

Non-blocking

Long-running tasks such as network requests can happen without freezing the entire page.

Synchronous example

console.log("First"); console.log("Second"); console.log("Third"); // Output: First Second Third

Asynchronous example

console.log("First"); setTimeout(() => { console.log("Second"); }, 1000); console.log("Third"); // Output: First Third Second
02 — THE WAITING ROOM

Promises

A Promise represents the eventual result of an asynchronous operation.

Three Promise states

  • Pending: The operation is still running.
  • Fulfilled: The operation completed successfully.
  • Rejected: The operation failed.
A Promise starts in the pending state. It eventually settles as fulfilled or rejected.
const myPromise = new Promise((resolve, reject) => { const success = true; if (success) { resolve("Task completed!"); } else { reject("Something went wrong"); } }); myPromise .then(result => { console.log(result); }) .catch(error => { console.log(error); });

Promise methods

Method Purpose
then() Runs when a Promise is fulfilled.
catch() Handles a rejected Promise.
finally() Runs after the Promise settles, either way.
Promise.all() Waits for all supplied Promises to fulfill, or rejects if one rejects.
03 — THE MODERN APPROACH

Async & Await

Async and await make Promise-based code easier to read and organize.

async keyword

Adding async before a function makes that function return a Promise.

async function greet() { return "Hello Student!"; } greet().then(message => { console.log(message); });

await keyword

await pauses the execution of its surrounding async function until the Promise settles.

async function getData() { const result = await fetchData(); console.log(result); } getData();
Remember: await can be used inside an async function. Modern JavaScript also supports top-level await in modules.
async function loadUser() { try { const response = await fetch("https://example.com/users"); if (!response.ok) { throw new Error("Request failed"); } const data = await response.json(); console.log(data); } catch (error) { console.error(error.message); } } loadUser();

05 — REAL WORLD SKILLS

Working with APIs

Web applications often request information from servers. The Fetch API helps JavaScript make HTTP requests.

What is an API?

An API is a way for different software systems to communicate and exchange information.

  • Request information from a server.
  • Receive a response.
  • Convert JSON into JavaScript data.
  • Display the result on the page.

Fetch workflow

fetch("/api/products") .then(response => { if (!response.ok) { throw new Error("Failed"); } return response.json(); }) .then(data => { console.log(data); }) .catch(error => { console.error(error); });
fetch() does not automatically reject for HTTP error responses such as 404 or 500. Check response.ok and handle errors yourself.
