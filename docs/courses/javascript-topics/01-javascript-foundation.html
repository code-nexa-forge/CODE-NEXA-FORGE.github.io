What is JavaScript?

Understand the role of JavaScript in web development.

JavaScript is a programming language mainly used to make websites interactive and dynamic.

HTML creates the structure of a webpage, CSS controls its appearance, and JavaScript adds behavior and functionality.

For example, when you click a button and a menu opens, JavaScript can handle that interaction.

01

Interactive Websites

JavaScript responds to clicks, typing, scrolling and other user actions.

02

Dynamic Content

It can update webpage content without requiring the entire page to reload.

03

Application Logic

It handles calculations, conditions, data and the logic behind web applications.

02 /

HTML vs CSS vs JavaScript

Three technologies working together to build a webpage.

01 — STRUCTURE

HTML

Creates headings, paragraphs, images, buttons and other webpage elements.

02 — DESIGN

CSS

Controls colors, layouts, spacing, typography and visual appearance.

03 — BEHAVIOR

JavaScript

Adds interactions, calculations, animations and dynamic functionality.

04 — RESULT

Complete Website

All three technologies work together to create a functional webpage.

index.html HTML + CSS + JS 
<!-- HTML: Structure -->
<button id="myButton">Click Me</button>

<!-- CSS: Appearance -->
<style>
    button {
        background: blue;
        color: white;
        padding: 12px 20px;
    }
</style>

<!-- JavaScript: Behavior -->
<script>
    document.getElementById("myButton")
        .addEventListener("click", function() {
            alert("Hello, welcome!");
        });
</script>
Remember the difference

HTML builds it. CSS styles it. JavaScript makes it interactive.

03 /

How JavaScript Works

Understand how your browser handles JavaScript code.

When a browser loads a webpage, it processes HTML, applies CSS and executes JavaScript.

JavaScript code is executed by a JavaScript engine. The engine reads and runs the instructions written by the developer.

Modern browsers include JavaScript engines that allow websites to respond to user actions and update content.

STEP 01

Browser Loads

The browser receives the webpage files.

STEP 02

Engine Reads

The JavaScript engine processes the code.

STEP 03

Code Executes

Instructions are executed by the engine.

STEP 04

Page Responds

The webpage can update and react to actions.

first-program.js YOUR FIRST JAVASCRIPT 
// Display a message in the browser console

console.log("Hello, JavaScript!");

// Display a message in an alert box

alert("Welcome to JavaScript!");
Where can you see console.log() output?

Open your browser's Developer Tools using F12, then select the Console tab. Your JavaScript console messages will appear there.

Common Beginner Mistakes

Understand a few mistakes you should avoid from the beginning.

!

Missing Quotation Marks

Text values need quotation marks. For example: console.log("Hello");

!

Incorrect Capitalization

JavaScript is case-sensitive. console.log() and Console.log() are not the same.

!

Misspelling Method Names

Use console.log() correctly. A spelling mistake can cause an error.

!

Ignoring Error Messages

Read browser console errors carefully. They often help you find the problem.
