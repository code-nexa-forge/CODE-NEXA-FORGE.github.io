01 — THE FOUNDATION

What are operators?

Operators are special symbols that perform operations on values and variables. They help JavaScript calculate, compare and make decisions.

example.js JavaScript 
let price = 500;
let quantity = 3;

let total = price * quantity;

console.log(total);

// Output: 1500

In this example, the multiplication operator (*) multiplies price by quantity and stores the result in total.

03 — COMPARING VALUES

Comparison operators

Comparison operators compare two values and return a Boolean result: true or false.

OPERATOR
MEANING
EXAMPLE
==
Loose equality
5 == "5" → true
===
Strict equality
5 === "5" → false
!=
Not equal
5 != 3 → true
!==
Strict not equal
5 !== "5" → true
>
Greater than
10 > 5 → true
<
Less than
5 < 10 → true
>=
Greater or equal
5 >= 5 → true
<=
Less or equal
4 <= 5 → true
comparison.js Example 
let age = 18;

console.log(age >= 18);

// Output: true
04 — CONNECTING CONDITIONS

Logical operators

Logical operators combine multiple conditions or reverse a condition.

OPERATOR
MEANING
EXAMPLE
&&
AND — both must be true
true && true
||
OR — at least one true
true || false
!
NOT — reverses the result
!true → false
logical.js Example 
let age = 20;
let hasID = true;

let allowed = age >= 18 && hasID;

console.log(allowed);

// Output: true

06 — DECISION MAKING

Conditional statements

Conditions allow JavaScript to execute different blocks of code depending on whether a condition is true or false.

STEP 01 Check condition
→
STEP 02 True / False

if statement

Executes a block of code when its condition is true.

else statement

Executes when the if condition is false.

else if statement

Checks another condition when previous conditions are false.

switch statement

Selects one block from multiple possible cases.

conditions.js Example 
let marks = 75;

if (marks >= 80) {
    console.log("Excellent!");
}
else if (marks >= 50) {
    console.log("You passed!");
}
else {
    console.log("Try again!");
}

// Output: You passed!
ternary.js Short condition 
let age = 19;

let result = age >= 18
    ? "Adult"
    : "Minor";

console.log(result);

// Output: Adult
