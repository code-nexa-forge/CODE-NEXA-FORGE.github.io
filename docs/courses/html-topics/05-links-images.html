01 / LINKS

A link is a doorway.

The anchor element creates a clickable connection. Its href attribute tells the browser where that connection should lead.

THE CONCEPT ANCHOR ELEMENT

Meet the <a> tag.

The anchor tag wraps around text or another element. When a visitor clicks it, the browser follows the destination written inside the href attribute.

<a href="https://example.com">Visit website</a>
Remember: href means Hypertext Reference. It contains the destination address of your link.

02 / UNDERSTAND THE ADDRESS

What's inside a URL?

A URL is the address of a resource on the internet. Different parts help the browser locate the correct website and page.

Example URL

https:// www.example.com /courses /html.html
Protocol
How the browser communicates securely.
Domain
The website's main address.
Folder
A section inside the website.
File
The particular page being requested.
ABSOLUTE LINK EXTERNAL ADDRESS

Go anywhere.

An absolute URL contains the complete web address, including its protocol and domain.

<a href="https://google.com">Google</a>
RELATIVE LINK LOCAL ADDRESS

Move within your site.

A relative URL points to a file or folder based on the current page's location.

<a href="about.html">About</a>

Understand a relative path

website/ → pages/ → about.html

If your current page is inside the pages folder, the link about.html points to another file in that same folder. Use ../ to move one folder level upward.

<a href="../index.html">Back to Home</a>
03 / LINK BEHAVIOUR

Choose how a link opens.

SAME TAB DEFAULT

Stay in the same tab.

This is the normal browser behaviour when no target attribute is specified.

<a href="about.html">About</a>
NEW TAB _BLANK

Open another tab.

Use target="_blank" when you want the destination to open in a new tab.

<a href="..." target="_blank" rel="noopener noreferrer">Open</a>
Security tip: When using target="_blank", include rel="noopener noreferrer" as a good security and privacy practice.
04 / IMAGES

Turn information into visuals.

The image element displays a picture on your webpage. It uses src for the image location and alt for a meaningful text alternative.

IMAGE ELEMENT IMG

Meet the <img> tag.

Unlike most HTML elements, img is a void element. It does not need a closing tag.

<img src="photo.jpg" alt="Mountain view">
Important: Always write useful alt text so people using screen readers can understand the image.
