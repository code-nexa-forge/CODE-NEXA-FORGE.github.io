01 / INTRODUCTION

What Are HTML Forms?

Imagine visiting a website and creating an account. You enter your name, email address and password. Then you click the Register button.

How does the website collect all this information? The answer is HTML Forms.

An HTML form is a section of a webpage that contains interactive controls. It allows users to enter information and submit it.

🔐

Login Forms

Collect usernames, emails and passwords to help users sign in.

📝

Registration Forms

Collect information when someone creates a new account.

💬

Contact Forms

Allow visitors to send questions and messages.

🔎

Search Forms

Allow users to search for products, articles or information.

Remember: HTML creates the form interface. A backend server is normally needed to receive, process and store submitted information.
02 / BASIC STRUCTURE

Understanding the Form Element

The <form> element is the main container for form controls. Everything that belongs to a form is generally placed inside it.

HTML / BASIC FORM
<form action="/submit" method="POST">
    <label for="username">Username:</label>
    <input type="text" id="username" name="username">
    <button type="submit">Submit</button>
</form>

How Does This Code Work?

1

<form>

Creates the form container.

2

<label>

Displays a description for the input field.

3

<input>

Allows the user to enter information.

4

<button>

Provides a button to submit the form.

The name attribute is important because it identifies the submitted field when the browser sends form data.
03 / INPUT TYPES

Explore Input Types

The <input> element is one of the most important form elements. Its type attribute decides what kind of information a user can enter.

HTML / INPUT EXAMPLES
<input type="text" name="fullname">
<input type="email" name="email">
<input type="password" name="password">
<input type="date" name="birthday">
<input type="file" name="document">
04 / INPUT ATTRIBUTES

Important Input Attributes

Attributes provide additional information and control the behaviour of form fields.

placeholder

Displays a hint inside an empty field.

placeholder="Your name"

value

Sets an initial value for a field.

value="Your Name"

required

Makes a field compulsory.

required

readonly

Prevents editing while keeping the value available for submission.

readonly

disabled

Disables the field and excludes it from form submission.

disabled

maxlength

Sets the maximum number of characters.

maxlength="30"
HTML / ATTRIBUTE EXAMPLE
<input
    type="text"
    name="fullname"
    placeholder="Enter your full name"
    maxlength="30"
    required
>
05 / LABELS & ACCESSIBILITY

Why Are Labels Important?

A label tells the user what information belongs in a field. It also helps screen readers understand form controls.

HTML / CONNECTING LABEL AND INPUT
<label for="email">Email Address</label>
<input
    type="email"
    id="email"
    name="email"
    placeholder="you@example.com"
>

The for attribute of the label must match the id of the input.

Clicking the label can also focus the connected input field. This makes forms easier to use.
06 / FORM CONTROLS

More Than Just Input Fields

HTML offers additional elements to build flexible and useful forms.

1. Textarea

Use <textarea> when users need to enter longer text, such as feedback or a message.

HTML
<textarea name="message" rows="5" cols="30">
</textarea>

2. Select and Option

Use <select> to create a dropdown list. Each choice is an <option>.

HTML
<select name="course">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="javascript">JavaScript</option>
</select>

3. Radio Buttons

Radio buttons let users select one option from a group. Use the same name for the group.

HTML
<input type="radio" name="level" value="beginner">
Beginner
<input type="radio" name="level" value="advanced">
Advanced

4. Checkboxes

Checkboxes allow users to select multiple independent choices.

HTML
<input type="checkbox" name="skill" value="html">
HTML
<input type="checkbox" name="skill" value="css">
CSS

5. Fieldset and Legend

Use <fieldset> to group related form controls and <legend> to give that group a title.

HTML
<fieldset>
    <legend>Personal Information</legend>
    <label for="student">Student Name</label>
    <input id="student" type="text">
</fieldset>
07 / FORM VALIDATION

Validate User Information

Validation helps ensure users enter information in the expected format before a form is submitted.

AttributeWhat It Does
requiredRequires a value before submission.
minlengthSets the minimum text length.
maxlengthSets the maximum text length.
minSets the minimum numeric/date value.
maxSets the maximum numeric/date value.
patternChecks text against a regular expression.
HTML / VALIDATION EXAMPLE
<form>
    <input type="email" required>
    <input type="password" minlength="8" required>
    <input type="number" min="18" max="60">
    <button type="submit">Register</button>
</form>
HTML validation improves the user experience, but it is not a security system. Always validate important data on the server as well.
