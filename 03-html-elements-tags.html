01 — UNDERSTAND THE ANATOMY

What makes an HTML element?

An HTML element usually consists of an opening tag, content and a closing tag. Together, these parts define a piece of webpage content.

THE ANATOMY OF A PARAGRAPH
<p> Hello World </p>
↑ Opening tag ↑ Content ↑ Closing tag
Opening Tag

Starts the element. Example: <p>

Content

The text or other elements placed between the tags.

Closing Tag

Ends the element. Example: </p>

03 — A SPECIAL CATEGORY

Not every element needs a closing tag.

Some HTML elements are called void elements. They do not wrap content and do not have separate closing tags.

<br>

Creates a line break in text.

<hr>

Represents a thematic break between content.

<img>

Embeds an image using its source and alternative text.

<input>

Creates an input control for user data.

04 — ELEMENT RELATIONSHIPS

HTML elements can live inside other elements.

This is called nesting. A parent element can contain child elements, helping you organize complex webpage structures.

PARENT ELEMENT: <div>
CHILD ELEMENT: <h2>

This heading is inside the parent div.

NESTED CHILD: <p>

This paragraph is also inside the parent div.
