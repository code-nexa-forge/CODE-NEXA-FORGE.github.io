01 / UNDERSTANDING RESPONSIVENESS

What is Responsive Design?

Responsive web design means creating websites that automatically adjust their layout, text, images and elements according to the screen size of the device being used.

▯

Mobile

Small screens need compact navigation, readable text and content arranged mostly in a single column.

SMALL SCREEN
▣

Tablet

Medium screens can show more content side by side, often using two-column layouts.

MEDIUM SCREEN
▭

Desktop

Large screens provide more room for navigation, multi-column layouts and larger content sections.

LARGE SCREEN
02 / MEDIA QUERIES

The power of @media

CSS media queries let you apply different styles depending on the screen width or other device characteristics.

Mobile Small screens. Example: 600px and below.
Tablet Medium screens. Example: 601px to 900px.
Desktop Large screens. Example: above 900px.
/* Default desktop layout */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Mobile layout */
@media (max-width: 600px) {
  .container {
    grid-template-columns: 1fr;
  }
}

04 / IMPORTANT TECHNIQUES

Three things to remember.

Flexible Widths

Use percentages, flexible grid units and max-width instead of forcing every element to have a fixed width.

width: 100%; max-width: 1100px;

Responsive Images

Images should scale inside their containers without overflowing or becoming distorted.

img { max-width: 100%; height: auto; }

Viewport Meta Tag

This tag tells mobile browsers to use the device width as the page's viewport width.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Mobile-First Design

Start with a simple layout for small screens, then add more complex layouts for larger screens.

@media (min-width: 768px) { ... }
