02 / ARRAYS

Meet the Array

An array stores multiple values in a single variable. Each value has a position called an index.

Creating an Array

Square brackets are used to create an array. Values are separated by commas.

const fruits = [ "Apple", "Mango", "Orange", "Banana" ]; console.log(fruits);

Accessing Array Values

Array indexing starts from zero. The first value is at index 0, not index 1.

const fruits = [ "Apple", "Mango", "Orange" ]; console.log(fruits[0]); // Apple console.log(fruits[1]); // Mango

04 / ARRAY METHODS

Work with Arrays

JavaScript provides built-in methods to add, remove, search and transform array values.

push()

Adds an element to the end of an array.

fruits.push("Grapes");
pop()

Removes the last element of an array.

fruits.pop();
unshift()

Adds an element to the beginning.

fruits.unshift("Kiwi");
shift()

Removes the first element.

fruits.shift();
includes()

Checks whether an array contains a value.

fruits.includes("Apple");
indexOf()

Returns the index of a value, or -1 if absent.

fruits.indexOf("Mango");
map()

Creates a new array from transformed elements.

nums.map(n => n * 2);
filter()

Creates a new array containing matching elements.

nums.filter(n => n > 5);
forEach()

Runs a function for every array element.

fruits.forEach(item => { console.log(item); });
05 / OBJECTS

Meet the Object

Objects store related information using key-value pairs. They are useful for describing real-world entities.

Student Object

name "Alex"
age 20
course "BSCS"
active true

What is an Object?

An object groups related properties together. Each property has a key and a value. You can access properties using dot notation or bracket notation.

const student = { name: "Alex", age: 20, course: "BSCS", active: true }; console.log(student.name); console.log(student["age"]);
06 / OBJECT FEATURES

More powerful object concepts

Objects can contain functions, other objects and nested data.

Object Methods

A function stored inside an object is commonly called a method.

const user = { name: "Alex", greet: function() { return "Hello!"; } }; console.log(user.greet());

Nested Objects

An object can contain another object as one of its property values.

const student = { name: "Alex", address: { city: "Multan", country: "Pakistan" } }; console.log(student.address.city);

Destructuring Arrays

Destructuring extracts values from an array into separate variables.

const colors = [ "Red", "Blue" ]; const [first, second] = colors; console.log(first);

Object Destructuring

You can extract object properties into variables using their matching property names.

const user = { name: "Alex", age: 20 }; const {name, age} = user; console.log(name);
