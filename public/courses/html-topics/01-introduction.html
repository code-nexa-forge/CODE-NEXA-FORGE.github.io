01 — THE FOUNDATION

So, what exactly is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on the web. Think of it as the skeleton of a website.

01.

HTML gives structure.

It tells the browser which content is a heading, which content is a paragraph, where an image belongs, and where a link should take the visitor.

first-page.html
<h1> Hello, World! </h1>
<p> My first webpage. </p>
02 — WHY HTML MATTERS

Every website starts somewhere.

From simple blogs to massive online platforms, HTML helps organize the content users see and interact with.

🏗️

Website Structure

Organize headings, paragraphs, sections, navigation and content.

🖼️

Media & Content

Add images, videos, audio, links and other useful content.

♿

Accessibility

Use meaningful elements to make content easier to understand and navigate.

03 — UNDERSTANDING THE PROCESS

How does HTML work?

You write HTML in a file. Your browser reads the markup and builds the webpage that appears on your screen.

STEP 01

Write HTML code

Create an HTML file and write elements such as headings, paragraphs and images.

STEP 02

Browser reads the code

The browser parses the HTML and understands the document structure.

STEP 03

Webpage appears

The browser renders the content so visitors can view and interact with it.

04 — THE THREE BUILDING BLOCKS

HTML, CSS and JavaScript.

Modern frontend development commonly uses three core technologies. Each one has a different responsibility.

🧱

HTML

Creates the structure and content of a webpage.

🎨

CSS

Controls the appearance, layout, colours and responsive design.

⚡

JavaScript

Adds behaviour, logic and interactivity to a webpage.
