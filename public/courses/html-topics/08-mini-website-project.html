02 / THE BRIEF

What are we building?

Personal Portfolio Website

Imagine you're introducing yourself to the world. Your portfolio should tell visitors who you are, what you do, what you've built and how they can contact you.

  • A page title and a main heading
  • An About Me section with a paragraph
  • A Skills section using an HTML list
  • A Projects section with project descriptions
  • A Contact section with useful links
  • Correct HTML document structure

04 / BUILDING GUIDE

How to build it properly

Understand the job of every important section before you customize your portfolio.
01

Start with the document structure

Use <!DOCTYPE html>, <html>, <head> and <body> to create a valid HTML document.

02

Introduce yourself

Use a main <h1> heading and a short paragraph to tell visitors who you are.

03

Organize your skills

Use <ul> and <li> to present skills in a clear list.

04

Show your projects

Add project names with <h3> headings and explain each project using paragraphs.

05

Make contact possible

Use an anchor tag with a useful href value to let visitors contact you.
