02 / HTML LISTS

Understanding HTML Lists

HTML provides three main types of lists for organizing content.

1. Unordered List

An unordered list displays items with bullet points. It is useful when the order of items does not matter.

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>
Browser Output:
  • HTML
  • CSS
  • JavaScript
Remember: The ul element creates the list, while each li element represents an individual item.

2. Ordered List

An ordered list displays items in a numbered or ordered sequence. It is useful for instructions and step-by-step processes.

<ol> <li>Open your browser</li> <li>Visit a website</li> <li>Start learning</li> </ol>
Browser Output:
  1. Open your browser
  2. Visit a website
  3. Start learning

You can also use the type attribute to change the numbering style.

<ol type="A"> <li>First item</li> <li>Second item</li> </ol>

Common types include 1, A, a, I and i.

3. Description List

A description list is used to display terms with their explanations or descriptions.

<dl> <dt>HTML</dt> <dd>Structures web content.</dd> <dt>CSS</dt> <dd>Styles web content.</dd> </dl>
Browser Output:
HTML
Structures web content.
CSS
Styles web content.
Important tags: dl = description list, dt = description term, dd = description details.
03 / HTML TABLES

Working with HTML Tables

Tables are useful for displaying structured data such as student records, schedules, prices and results.

What is an HTML Table?

An HTML table organizes information into rows and columns. Each row contains cells that hold data or headings.

<table> <tr> <th>Name</th> <th>Age</th> </tr> <tr> <td>Ali</td> <td>20</td> </tr> </table>
Name Age
Ali 20
Ahmed 22
<table>

Table Element

Creates the main table structure.

<tr>

Table Row

Creates a horizontal row inside a table.

<td>

Table Data

Creates a normal data cell.

Understanding Table Headings

The <th> element defines a heading cell. It helps identify the meaning of each column.

<tr> <th>Student Name</th> <th>Marks</th> <th>Grade</th> </tr>
Use meaningful table headings and consider adding a caption to explain what the table represents.

Adding More Rows and Columns

You can add as many rows and cells as required. Each tr element creates another row.

<table> <tr> <th>Course</th> <th>Duration</th> <th>Level</th> </tr> <tr> <td>HTML</td> <td>2 Weeks</td> <td>Beginner</td> </tr> <tr> <td>CSS</td> <td>3 Weeks</td> <td>Beginner</td> </tr> </table>

Using Colspan and Rowspan

Sometimes you need one cell to cover multiple columns or multiple rows. HTML provides two attributes for this.

colspan

Merge Columns

Allows a cell to extend across multiple columns.

rowspan

Merge Rows

Allows a cell to extend across multiple rows.

<table border="1"> <tr> <th colspan="2">Student Details</th> </tr> <tr> <td>Ali</td> <td>20</td> </tr> </table>
Colspan and rowspan change the space occupied by a cell. They do not automatically create extra cells.
